# Containerized Flask Portfolio Application

A portfolio web application developed using Flask and Docker. This project demonstrates backend web development, containerization, and deployment practices using modern development tools.

## Features

* Built with Python and Flask
* Responsive web interface
* Docker containerization
* Version control using Git
* Structured project architecture

## Technologies Used

* Python
* Flask
* HTML
* CSS
* Docker
* Git

## Project Structure

- app.py
- requirements.txt
- Dockerfile
- static/
- templates/
- README.md

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Run with Docker:

docker build -t flask-portfolio .

docker run -p 5000:5000 flask-portfolio
